# A small, honest user study

Status: **not run**. The public repository trial is a static engineering check,
not evidence that maintainers or users want this product.

Recruit three to five engineers who recently changed a dependency, deployment,
or customer-facing commitment. Use participant aliases and ask permission before
recording. Do not send repository content to models without the owner's consent.

## Twenty-minute session

1. Ask for a recent decision that became outdated. Where was it recorded? Who found the mismatch?
2. Give them the local migration demo without explaining the map. Ask them to identify
   what changed, which work is affected, who owns it, and the evidence behind the finding.
3. Time those tasks. Record mistakes and any explanation they needed.
4. Ask them to record a replacement decision and review an affected decision.
5. Let them compare the result with searching messages and reading the repository directly.
6. Ask: would you run this on a real repo? What would cause you to ignore an alert?
